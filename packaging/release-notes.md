Turn any song into a Clone Hero chart that follows the guitar.

**To install:** download `ch-autochart-setup.exe` below and run it. Windows 10 or 11 (64-bit).

Windows may show "Windows protected your PC" because the installer isn't code-signed. Click **More info**, then **Run anyway**. It installs for your user only, with no admin prompt, and can be removed from Settings → Apps.

**To use:** open ch-autochart from the Start menu, drop in a song, review which instrument the chart follows, add album art, and save. If it finds your Clone Hero Songs folder (or you point it there once), finished charts go straight into the game; then choose Settings → General → Scan Songs in Clone Hero.

Splitting a song into instruments takes a few minutes per song on most PCs. Everything runs on your computer.
